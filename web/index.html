开始使用 Pulse

  1. 添加完整的 HTTP 或 HTTPS 网址，并设置检查间隔和超时。
  2. 启用目标后会自动检查；“立即检查”可以手动触发，暂停目标也可手动检查。
  3. 点击目标名称或“历史”查看明细与UTC日汇总。默认200–299通过；配置业务规则后还需满足全部规则，仍不代表完整业务流程正常。
  4. 编辑不删除旧记录，历史会保留检查时的网址；删除目标则同时删除它的历史。

页面仅供本机使用。请勿在监测网址中填写账号密码或敏感令牌。
