# 完成度与首版验收

最初检查于2026-11-06，本文随2026-11-07的v1.0.0交付更新。

## 已完成的本机功能

单网址CLI、多目标管理、有界并发及同目标去重、自动/手动检查、SQLite历史及持久化、JSON API、搜索筛选、分页与趋势、手机视口布局。200–299为本次HTTP通过，不代表全部业务健康。

本版继续限制为本机个人工具，不提供公网认证、通知、多租户或多实例协调；允许本机/内网目标，不提供SSRF隔离。详细架构、API和边界见README。

## 验证与资料

- 本地Go全套测试、vet、前端两项时序回归通过；本地语句覆盖率82.5%，不是完成百分比。
- 动态演示启动、冲突、重复启动与失败清理已补测试；真实Windows独立控制台Ctrl+C已验证取消、端口释放和持久化。Unix对应SIGINT由CI验证。
- 三项Chromium自动流程在本机通过：完整管理与错误校验；55条历史50+5分页、切换/删除与320/390视口；真实服务断开与同库恢复。
- 验收脚本通过陈旧身份零写入拒绝、四槽位饱和后完成55条真实历史两项集成回归。
- 18组真实HTTP50毫秒调度实测及100×1000条合成历史查询基准已完成，见 [性能报告与原始数据](performance/README.md)。
- 下载包白名单及全新目录启动验收通过，测试时PATH不含Go/Node；最终发布还要求下载远程包复核SHA256并启动。

## 远程发布门槛

`.github/workflows/ci.yml` 在Windows、Ubuntu运行检查，Ubuntu启用CGO执行race。正式标签只允许指向两个作业全部成功的提交；工作流文件存在、本机测试通过或单次推送成功都不能代替远程结果。

最终提交、CI链接、Release和制品校验结果由GitHub Release说明交付。当前状态请查 [Actions](https://github.com/XiuGuang-Alter/pulse-go-monitor/actions) 和 [Releases](https://github.com/XiuGuang-Alter/pulse-go-monitor/releases)，不沿用历史本地后台服务状态。

## 实际限制

Windows本机无C编译器，race必须由Ubuntu CI取得实际结论；不把本机跳过当通过。手机只验证浏览器视口，未覆盖真机、触摸和移动键盘。没有生产长期SLA、多浏览器保证或未测性能指标。测试只能证明已经执行的路径，不能证明没有任何缺陷。
