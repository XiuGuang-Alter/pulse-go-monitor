## 独立24小时实跑

Windows/PowerShell7在干净候选提交上启动（将实验与其它压力测试串行安排）：

```powershell
.\scripts\soak-session.ps1 -Action Start -Seconds 86400
.\scripts\soak-session.ps1 -Action Status
```

启动器返回独立worker身份和本机证据路径，默认记录在忽略目录 `.cache/soak-active-session.json`，不会修改系统睡眠设置。电脑需持续运行；单调时间或UTC采样间断超过30秒会使实验失败，不将休眠算作通过。每次新实验必须使用新目录，失败不自动重启掩盖。Status会核对进程路径和启动时间；成功结果还须绑定worker、足额测量时长、完成阶段及清理成功，不能将60秒预检冒充24小时。

独立数据为100目标、并发4、间隔10秒、超时1秒，混合正常、HTTP500、超时和业务断言失败。约10秒一次观察，周期编辑、暂停/恢复、删除替换与历史/日汇总查询。每目标进展使用最新检查ID，明细1000条封顶后仍可检测；总量使用本进程成功落库计数基线差，绑定实例。重启持久化单独记录，不跨实例相减。

每个实验目录保留environment、samples.csv、progress、result/failure和restart。包含源提交、产品与运行脚本指纹、二进制SHA及构建参数；记录堆、goroutines、RSS、DB/WAL/SHM大小、旋转抽样的到期等待/排队延迟。抽样不是所有目标延迟分布，分配文件大小不是有效记录数，RSS也不是Go堆。工具会话中断后可再次读取Status；缺结束记录只表示未完成，不能宣布通过。

短预检可使用 `-Seconds 60 -MutationSeconds 15 -AllowDirty -SessionFile .cache/preflight-session.json`，但24小时验收不允许-AllowDirty或缩短变更周期。恢复、暂停、计数封顶、饥饿、日志写入失败、接口失败、实例改变、计数回退、采样间断和清理失败均有脚本回归。后台启动器对缺失会话目录、同会话并发启动、发布记录失败和日志碰撞也有验证；启动记录发布失败会核对身份后清理本次私有进程树。

24小时完成后必须核对原始记录与当前运行代码，再执行完整性能对照、处理重要退化，归档Edge界面验收与最终交付检查。最终提交双系统CI、升级/恢复、下载包与发布后下载复验仍是独立门槛。
