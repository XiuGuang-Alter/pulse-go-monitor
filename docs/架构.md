# 架构与取舍

单进程本机监测工具。CLI检查单网址，serve同时提供调度、SQLite、JSON API和内嵌页面。

```text
main / serve
  ├─ server → JSON API / embedded web
  ├─ scheduler → bounded slots + per-target running set → Check
  └─ store → SQLite targets / checks
```

Check等待最终响应头并分类，context绑定HTTP请求。调度器每250毫秒读取到期目标，完成后再安排间隔，繁忙时等后续轮询，不积压无界队列。

SQLite单连接简化事务；网络不占用事务。编辑递增版本，旧检查可归档快照，但只有同版本才能更新下次时间。删除有存在性检查和外键级联，历史按ID游标分页。

退出取消调度和HTTP请求，等待收尾，再关闭服务、数据库；主动取消不作为目标故障。Windows真实Ctrl+C在独立隐藏控制台验证，Unix验证SIGINT。

原生HTML/CSS/JS串行刷新、以代次作废旧响应，防止写入期间回滚旧配置。手机历史表格在弹窗内部滚动，不撑宽页面。

SQLite和内嵌前端让单程序即可运行；代价是单进程协调、单连接吞吐限制，改网页后也要编译。不承诺多实例协调、完整鉴权、SSRF隔离或公网能力；性能数字限于报告环境。
